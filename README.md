# **考公题型**
## **资料分析**
**题型考查**：增长率，基期量，增长量，年均增长量，现期量，现期比重，基期比重，**两期比重**，平均数，倍数，间隔增长率，年均增长率，混合增长率，平均数增长率，乘积增长率，增长率比较，增长量比较，比重、平均数比较
公式积累
1. **增长率：** $\frac{现期量-基期量}{基期量} = \frac{增长量}{基期量} = \frac{增长量}{现期值-增长量} = \frac{现期量}{基期量} - 1$
2. **基期量：** $现期量-增长量 = \frac{现期量}{1+增长率} = \frac{增长量}{增长率}$
3. **增长量：** $现期量-基期量 = \frac{现期量}{1+增长率} \times 增长率 = 基期量 \times 增长率$
4. **年均增长量：** $\frac{末期量-初期量}{间隔年份}$
5. **现期量：** $基期量+n \times 增长量 = 基期量(1+r)^n$
6. **现期比重：** $$\text{比重} = \frac{\text{部分量}}{\text{总体量}} = \frac{A}{B}$$，部分量 = 总量 × 比重，总体量 = 部分量 ÷ 比重
7. **基期比重：** $$\frac{\text{现期部分量}}{\text{现期总体量}} \times \frac{1+\text{总体增长率}}{1+\text{部分增长率}} = \frac{A}{B} \times \frac{1+b\%}{1+a\%}$$ $$\frac{\text{现期部分量}-\text{增长量}}{\text{现期总体量}-\text{增长量}}$$
9. **两期比重：** $现期比重 - 基期比重 = \frac{现期部分量}{现期总体量} \times \frac{部分增长率-总体增长率}{1+部分增长率} = \frac{A}{B} \times \frac{a\%-b\%}{1+a\%}$
   $= \frac{现期部分量}{现期总体量} - \frac{现期部分量-增长量}{现期总体量-增长量}$
10. **比重相关公式、平均数相关公式、倍数相关公式均为比值相关，公式模型一致**
11. **间隔增长率：** $r_1 + r_2 + r_1 \times r_2$
12. **年均增长率：** $\frac{末期量}{初期量} = (1+r)^n$
13. **混合增长率：** 居中、偏大、线段法
14. **平均数增长率：** $\frac{a\%-b\%}{1+b\%}$
15. **乘积增长率：** $a\% = b\% + c\% + b\% \times c\%$
